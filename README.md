# setup-skills

Skills do Claude Code para começar e organizar projetos.

| Skill | O que faz |
|---|---|
| [`optimize-workspace`](skills/optimize-workspace/SKILL.md) | Organiza o trabalho em etapas ICM com dados em OKF e fecha projetos de software com o protocolo de otimização de desempenho. |

## Como instalar

Copie a pasta da skill para um destes lugares:

- `.claude/skills/` do projeto, para valer só nele;
- `~/.claude/skills/`, para valer em todos os seus projetos.

```bash
git clone https://github.com/Graail/setup-skills.git
cp -r setup-skills/skills/optimize-workspace ~/.claude/skills/
```
